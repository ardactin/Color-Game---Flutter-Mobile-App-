# Color Game - Flutter Mobile App

A simple mobile game built with Flutter where the user taps the green color to score points.

## Features
- Tap the green square to increase your score
- Colors shuffle after each tap
- Simple and intuitive UI

## How to Run
1. Clone this repository
2. Open the project in Android Studio or VS Code
3. Run `flutter pub get` to install dependencies
4. Launch the app on an emulator or device
